## 一、功能概述

在**截图流程里无缝切换录屏**：框选区域后，点工具条上的"录屏"按钮即进入录制；
录制中显示一根**可拖动的细条条**（复用截图工具条视觉）：计时、麦克风/系统声音开关、暂停、停止；
停止后进入**编辑窗**：预览、倍速、裁剪（掐头去尾）、复制、保存。

核心能力：

- **区域录制**：与截图共用同一套框选（手动拖拽 / 智能选窗），只录选中区域
- **音频双开关**：麦克风 / 系统声音（内录）**独立开关**，录制中也能切换
- **简单编辑**：倍速（0.5x / 1x / 1.5x / 2x）+ 时间裁剪（首尾把手）
- **输出**：保存 MP4（默认 `视频\轻启录制\`）+ 复制（文件引用，可直接粘贴到 QQ/微信发送）

## 二、用户流程与 UI

### 2.1 流程（复用截图 UI）

```
Alt+D 截图 → 框选区域
   ├─ 工具条画图标注 → 复制/保存/钉图（现状不变）
   └─ 点「录屏」按钮（● 录制图标）→ 切换到录制模式
         ├─ 录制前：细条条显示 [区域尺寸] [麦克风●] [系统音♪] [开始]
         ├─ 录制中：细条条显示 [⏱ 计时] [麦克风●] [系统音♪] [⏸ 暂停] [■ 停止]
         └─ 停止 → 编辑窗（预览播放 + 倍速 + 裁剪 + 复制/保存）
```

- 覆盖层在录制开始时**自动隐藏**（露出真实内容，同长截图遮罩思路）；选区边框可选保留细线
- **细条条**：与截图工具条同款深色圆角、可拖动、吸附安全区；不抢焦点、对截屏隐形
- **编辑窗**：视频预览（MediaElement）+ 时间轴（起止裁剪把手）+ 倍速选择 + 时长/大小 +
  [复制] [保存] [另存为…]

### 2.2 入口

1. 截图工具条第一排新增「录屏」按钮（`L` 键之外的图形入口，快捷键 `R` 与矩形工具冲突 → 用 `V`？**建议不设快捷键**，按钮为主）
2. 托盘菜单追加「录屏」= 直接框选后录制（与"截图"菜单项平行）
3. 设置·截图页可改默认帧率/音频开关/保存目录

## 三、技术方案

### 3.1 采集方案对比（关键决策）

| 方案 | 原理 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- | --- |
| **A. GDI 逐帧**（CopyFromScreen 升级版） | 独立线程按帧率截取区域 | 零新依赖、区域天然支持、复用现有截图代码 | CPU 中等（1080p@30 ≈ 15~30%）；**硬件叠加/受保护视频拍不到（黑屏）** | **v1 推荐** |
| B. Windows.Graphics.Capture | WinRT 系统级采集（D3D 纹理） | 高效、游戏/视频都能拍、系统自带 | 需要 Windows 10 1803+、TFM 升级为 `net9.0-windows10.0.*`、区域需按帧裁剪 | v2 升级方向 |
| C. DXGI Desktop Duplication | 显卡桌面复制 | 极高效、全内容 | DirectX 互操作代码量大 | 备选 |
| D. 外置 FFmpeg | gdigrab 区域采集 | 后处理（倍速/裁剪）一行命令 | 体积 +100MB、外部依赖 | 不采用 |

**v1 = A（GDI）**，管线预留 `IFrameSource` 接口，v2 可无缝换 B/C；
**如实告知边界**：录普通应用/网页/文档完美；录全屏游戏、部分播放器的硬解视频可能黑屏（v2 用 WGC 解决）。

### 3.2 音频

- **NAudio**（MIT 协议 NuGet）：
  - 麦克风：WASAPI capture（默认输入设备）
  - 系统声音：WASAPI **loopback**（默认输出设备内录）
- 两路 PCM（48kHz）各自开关；同开时混音为立体声
- 录制中切换开关：分段写入（换挡处无爆音，时间轴连续）

### 3.3 编码封装

- **Media Foundation SinkWriter**（系统自带，P/Invoke COM）：
  - 视频：H.264（硬件编码器优先，回落软件），帧率 15/24/30 可选，码率按区域大小自适应
  - 音频：AAC 128~192kbps
  - 封装：MP4
- 无音频时输出纯视频轨；帧时间戳用 Stopwatch 对齐，音视频同步误差 < 40ms

### 3.4 后处理（编辑窗）

- **时间裁剪**：起止把手 → 导出时重编码（Media Foundation 转码管线，裁掉段不写入）
- **倍速**：0.5x / 1x / 1.5x / 2x —— 视频按新帧时长写入 + 音频变调/重采样（导出时应用）
- **画幅裁剪**：录制前选区即定画幅（不做二次画幅裁剪，保持"简单"定位）
- 编辑窗内的"复制/保存"= **导出后**动作（应用倍速与裁剪），默认保存一份原始文件 + 导出文件

### 3.5 性能预算

- 1080p 区域 @30fps：CPU 目标 < 25%（硬件 H.264）、内存 < 200MB、输出 ~1.5MB/秒（8Mbps）
- 帧采集与编码分离线程 + 有界队列；编码落后时丢帧不卡录制

   开关态用主题色高亮（同截图工具按钮选中态）

## 六、设置项

**设置·截图 页新增「录制」区块**（录屏属于截图家族）：

- 默认帧率：15 / 24 / 30（默认 30）
- 默认音频：麦克风开关、系统声音开关（默认：麦关、系统音开）
- 保存目录（默认 `%USERPROFILE%\Videos\轻启录制\`，可浏览修改）
- 文件名模板（默认 `录屏_yyyyMMdd_HHmmss`，沿用截图模板机制）
- 录制时显示选区边框：开/关

## 七、实施计划（审核通过后）

1. `QuickPalette.Recorder` 库：`IFrameSource`（GDI 实现）+ NAudio 双音频源 + MF 编码器 + `RecordingSession`（可单测的时间轴/混音逻辑）
2. 截图工具条「录屏」按钮 + 录制细条条（复用拖动/主题）
3. 编辑窗（预览/倍速/裁剪/复制/保存）
4. 设置·截图「录制」区块 + 持久化
5. 托盘「录屏」入口
6. 实测：区域录屏 30s 验证音画同步/文件可播/倍速裁剪导出 → 本地打包（**不推送 GitHub**）

## 八、风险与边界

- **GDI 方案对硬件叠加内容（全屏游戏/部分播放器）黑屏** —— 已知边界，写入提示；v2 以 WGC 采集根治
- 长时间录制（>30 分钟）内存/文件分段策略：v1 单文件、内存驻留解码帧不累计（边录边写盘）
- 倍速的音频变调：v1 保持音高随倍速变化（与常见播放器"倍速"一致），不做变调修正
- 麦克风/系统音设备切换：v1 用系统默认设备，录制中拔插设备按静音段处理
- 权限：首次录音可能触发麦克风隐私授权提示（系统行为）
