# 轻启 QuickPalette · 开发与测试指南

## 1. 环境要求

- Windows 10/11 x64
- .NET 9 SDK（含 Windows Desktop 工作负载）
- 可选：Inno Setup 6（编译安装包）

## 2. 构建与测试

```powershell
dotnet build QuickPalette.sln -c Debug        # 全量构建
dotnet test QuickPalette.sln -c Debug         # 运行全部 xunit 测试
dotnet run --project src\QuickPalette.App     # 运行主程序
```

- 测试项目：`tests\QuickPalette.Domain.Tests`（搜索/过滤/拼音/事件总线）、`tests\QuickPalette.Infrastructure.Tests`（存储/迁移/文件索引/启动器）。
- IO 类测试使用 `%TEMP%` 下临时目录并在结束时清理，可重复运行。

## 3. 数据格式与存储

所有用户数据位于 `%APPDATA%\QuickPalette\`：

| 文件 | 内容 |
| --- | --- |
| `apps.json` | 白名单应用（含 `schemaVersion` 版本信封、收藏/别名/标签/拼音/使用统计冗余字段） |
| `settings.json` | 配置（热键、主题、过滤规则、扫描来源、MaxResults 等） |
| `hidden.json` | 隐藏记录（key 规范化小写路径/AUMID/名称，防止候选池"复活"） |
| `usage.json` | 使用统计（次数、最近使用时间，供排序与"最近使用"展示） |
| `backups\` | 自动备份：`apps_*` / `settings_*` / `pre_migration_*` **按类别各保留最近 10 份**，写主文件前先备份 |
| `FileIndex\` | 文件索引快照 `index.bin` + `index.meta.json`（Version/Count/Status/Volumes） |
| `logs\` | 滚动日志 `app-yyyyMMdd.log` |
| `firstrun.done` | 首次向导完成标记 |

**写入安全**：统一临时文件 + `Flush(true)`（fsync）+ 原子替换；读失败不覆盖写（区分"文件不存在/损坏/IO 失败"）；损坏时按时间倒序从最近可读备份恢复并记录日志。

**导入/导出**：设置页可导出单一 `quickpalette-backup.json`（apps + settings + schemaVersion + 导出时间），导入前自动备份现有数据。

## 4. 文件索引子系统（可选功能，设置中可关闭）

```
主进程(普通权限)                    FileIndexWorker(提权，requireAdministrator)
  │  ShellExecuteEx("runas") ──────► 启动，参数 --parent <pid>
  │                                    │  打开各 NTFS 卷读 USN 变更日志
  │                                    │  全量枚举 MFT + 增量应用变更
  │  每 5s 轮询 index.meta.json ◄──────┤  版本号变化时原子写 index.bin/meta
  │  Version 变化 → 双缓冲热加载        │  监控父进程存活（PID+启动时间）自行退出
  │  写 rebuild.request ─────────────►  轮询到标记 → 全量重建并删除标记
```

- 快照格式：QPFS v4，二进制流式读写（不整表驻留），UTF-8 + 7-bit 长度前缀字符串。
- 索引内容：FRN → (父 FRN, 名称, 时间, 属性)，查询时按父链拼出完整路径，仅在查询结果里携带大小等元数据。
- 协议稳定性：`index.bin`/`index.meta.json`/`rebuild.request` 三个文件的语义是主/子进程契约，改动需两边同步。

## 5. 搜索与排序规则（Domain）

匹配维度**分层**（层内排序不影响跨层优先级）：

1. 名称精确 → 2. 名称前缀 → 3. 名称子串 → 4. 拼音全拼 → 5. 拼音首字母 → 6. 别名/标签/DisplayName

层内加分：收藏 `+100`、`launchCount × 2`、`SortWeight`、最近使用指数衰减 `50·exp(-天数/半衰期≈7天)`。

空输入 = 收藏 + 最近使用（不混入从未使用的条目）。`maxResults` 默认 10，可在设置中调整并热更新。

拼音由内置码表生成（`PinyinProvider`，含常用多音字备选读音），入库时写入 `Pinyin`/`PinyinInitials`；新增生僻字时可扩展码表或用别名兜底。

## 6. 过滤与去重（Domain）

- 关键词黑名单（uninstall/setup/helper/crash/…）+ 路径黑名单（System32 等，**按路径段匹配**，系统目录由 `%SystemRoot%` 推导）
- `FilterSystemComponents` 开启时过滤 WindowsApps 明显系统项
- `Whitelist` 优先于一切过滤（加白覆盖）
- 去重多键：exe 路径 / AUMID / 规范化名称，取舍优先级：用户级开始菜单 > 全局级 > 桌面 > 其他（非卸载目录优先）

## 7. 调试与诊断工具

| 工具 | 用途 |
| --- | --- |
| `tools\UsnDiag` | USN 卷原始字节级诊断（QUERY/ENUM/READ、产品解析路径实跑）；日志输出到 `%TEMP%` 或命令行指定 |
| `tools\ParseTest` | 索引快照诊断（格式解析、装载耗时/内存、中文查询实测）；查询词通过命令行传入 |

```powershell
dotnet run --project tools\UsnDiag -- --log D:\temp\usndiag.log
dotnet run --project tools\ParseTest -- "搜索词"
```

## 8. 发布

见 [build/README.md](../build/README.md)。发布必须同时携带 `QuickPalette.FileIndexWorker.*` 全套文件，否则文件搜索不可用。

## 9. 插件（V3 预留）

`QuickPalette.Plugins.Sdk` 提供 `PluginManifest`（名称/版本/入口/权限声明）与插件上下文契约（`IQuickPalettePlugin`/`IPluginContext`，位于 Domain.Contracts）。V1 只落契约与 SDK，加载器在 V3 实现；数据模型已预留 `customFields` 保证插件数据前向兼容。
