# 文档预览功能设计（v1）

## 1. 需求

- (a) 支持 PDF、Word(docx)、Excel(xlsx)、PPT(pptx)、MD、TXT 等主流文档格式。
- (b) 单击文档结果时，在面板旁边弹出预览窗口。
- (c) 设置中提供开关；关闭时单击文档不触发预览（恢复现有行为）。
- 约束：不改变现有搜索功能与内存优化措施。

## 2. 交互设计

| 场景 | 行为 |
|---|---|
| 单击一条文档类结果（文件结果且扩展名受支持） | 面板旁弹出预览窗口，异步加载并显示内容 |
| 单击另一条文档 | 原地切换内容（旧加载取消） |
| 单击应用/命令/不支持格式/文件夹 | 预览窗口隐藏（保持现状语义） |
| 面板隐藏（Esc/失焦/启动目标） | 预览窗口一并隐藏 |
| 预览窗口获得焦点（滚动/选中复制） | 面板不自动隐藏（避免预览交互误杀面板） |
| 预览窗口失焦到其他应用 | 预览与面板一并隐藏 |
| 双击/回车启动文档 | 现状不变（启动关联程序），预览随之隐藏 |
| 设置关闭"文档预览" | 单击文档不再弹预览（现有单击=选中行为） |

## 3. 窗口排版（布局）

```
┌──────────────────────────────────────────────┐
│  📄 文件名（加粗截断）  [PDF]            [×] │  标题栏：高 48；×固定 32×32 右上角
├──────────────────────────────────────────────┤
│                                              │
│  内容区（整窗可滚动、文本可选中复制）        │
│  · TXT/MD   正文文本（等宽字体，保留格式）   │
│  · DOCX     按段落抽取正文                   │
│  · PPTX     「── 幻灯片 N ──」分节           │
│  · XLSX     对齐列文本表格（前 50 行×10 列） │
│  · PDF      文本模式（抽取前 5 页文本）      │
│                                              │
├──────────────────────────────────────────────┤
│  单击左侧结果可切换预览                      │  底部提示条（同面板视觉语言）
└──────────────────────────────────────────────┘
```

- 尺寸：宽 440；高 = min(面板高, 工作区高 − 40)，最小 360。
- 位置：紧贴面板右缘外 12px、顶部对齐；右侧放不下则贴左缘；仍放不下钳入工作区。
- 视觉：圆角 12、BgWindow 背景、同款描边/阴影、DynamicResource 主题响应、深浅色自动跟随。
- 加载态：内容区显示"加载中…"；失败/超大显示明确提示。

## 4. 格式解析与内容上限（内存友好）

| 格式 | 解析方式（零第三方依赖） | 上限 |
|---|---|---|
| TXT/MD | 直接读文本 | 200KB / 2000 行 |
| DOCX | ZipArchive → word/document.xml → w:t 段落 | 前 2000 段 |
| PPTX | ZipArchive → ppt/slides/slide*.xml → a:t | 前 30 张 |
| XLSX | ZipArchive → sharedStrings + sheet*.xml → 对齐文本 | 50 行 × 10 列 × 前 3 表 |
| PDF | Flate 解压内容流抽取 Tj/TJ 文本（文本模式） | 前 5 页 |
| 其他 | 不支持提示（旧版 .doc/.ppt/.xls 二进制格式明确提示） |

- 抽取全部在 `Task.Run` 后台执行 + `CancellationToken`（切换/关闭即取消）；只保留上限内字符串，
  不缓存整文件字节（流式读 Zip 条目），与索引/搜索内存路径零交集。

## 5. 分层与改动面

| 层 | 改动 |
|---|---|
| Domain | `Settings.PreviewEnabled`（默认 true） |
| Infrastructure | 新增 `Preview\DocumentTextExtractor`（纯函数式抽取，单元测试覆盖六类格式） |
| App | 新增 `PreviewWindow`；MainWindow 单击接线与生命周期联动；设置页新增开关；UiText 双语文案 |

不改动：SearchEngine/FileSearchEngine/索引 Worker/内存压缩存储（零接触）。

## 6. 开关

- 设置 → 通用 → "单击文档时显示预览"（默认勾选），随"保存"持久化，立即生效。
- 关闭时预览窗口强制隐藏，单击行为回归"仅选中"。

# v2 增补：PDF 图文渲染 与 图片预览

（针对 v1 的 PDF 文本模式乱码问题——中文字体为 CID 编码，文本抽取无法还原。）

## PDF：逐页图文渲染（Windows.Data.Pdf 系统引擎）

- **渲染引擎**：Windows.Data.Pdf（系统自带，与 Edge/系统阅读器同款），图文/字体/排版完整还原。
- **调用通道**：Windows PowerShell 5.1 的 WinRT 桥（`-EncodedCommand` + 脚本内嵌字面量）——
  .NET 9 离线环境无 WinRT 投影包，PowerShell 5.1 系统必带，是零依赖稳定通道。
- **两个坑与对策**（均已单元/实机验证）：
  1. WinRT 文件代理（`StorageFile.GetFileFromPathAsync`）在受限令牌下被拒
     → 改为纯 .NET 读字节 + `InMemoryRandomAccessStream` 喂给渲染引擎；
  2. `IAsyncOperation` 无 `IsCompleted` 属性（轮询恒真）
     → 一律经 `AsTask` 包成 Task 再轮询；`Task.Wait(int)` 在 PS 5.1 偶发绑定异常
     → 全部改零方法绑定的 `IsCompleted + Sleep` 轮询（带超时）。
- **输出**：前 8 页 PNG（宽 900px，高度按页比例），窗口内纵向连续显示（阅读器体验）；
  页数超过预览上限时底部提示"共 N 页 · 预览前 8 页"。
- **降级**：渲染桥不可用/失败 → v1 文本模式（如实标注）。

## 图片预览

- 支持 png/jpg/jpeg/bmp/gif/tiff/ico，直接位图化显示（WPF 内置编解码，零依赖）。
- 解码宽度封顶 1000px（超大照片重采样，控制解码内存）；隐藏即释放位图引用。

## 内存约束

- PDF 页 PNG 每页约 50-200KB，解码后按 1000px 宽封顶；最多 8 页；
- 切换/隐藏即取消旧渲染并清空位图；与索引/搜索内存路径零交集。
