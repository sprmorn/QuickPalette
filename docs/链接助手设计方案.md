# "轻启"链接助手 · 设计方案（调研稿，待审核）

> 版本：v0.1（2026-11-12）
> 状态：**待审核** —— 审核通过后再进入开发；开发完成后本轮不推送 GitHub，待全部功能稳定后统一发布。

---

## 一、功能概述

**链接助手**：当系统剪贴板出现可识别的链接时（如百度网盘分享、磁力链接、腾讯会议入会链接、远程协助链接、
音乐/视频链接，以及**普通网页链接**等），在**屏幕右上角**弹出一张轻量提示卡，询问"是否跳转到对应软件进行操作"，
一键 `打开` / `忽略`。

核心体验：

- 复制链接 **立即感知**（事件驱动，非定时轮询）；
- **不复制就不弹**、同一条链接不重复弹、轻启自己的复制不弹（截图等）；
- 提示卡**不抢焦点**、自动收起、可手动关闭；
- 只在**对应软件已安装**时提示跳转（没装就安静/或提示网页版）。

### 2.6 网页链接（普通链接 → 提示跳转浏览器打开）【新增】

| 内容 | 链接特征 | 唤起方式 | 目标软件 |
| --- | --- | --- | --- |
| 普通网页 | `http(s)://...`（未命中以上任何类目） | 默认浏览器打开 | 浏览器 |

- 这是**兜底类目**：只要复制的是链接且前面各类都没命中，就提示"用浏览器打开"；

  且该类目默认**可一键关闭**（设置·工具箱·链接助手·"网页链接"开关）。

## 三、方案实施与技术细节

### 3.1 总体架构

```
ClipboardLinkMonitor（监听） → LinkClassifier（识别分类） → LinkPromptWindow（提示卡） → LinkLauncher（跳转）
                                       ↑
                              设置·工具箱「链接助手」（开关/规则/免打扰）
```

- `Services/ClipboardLinkMonitor.cs`：剪贴板监听（消息钩子，零轮询）；
- `Services/LinkClassifier.cs`：纯逻辑识别器（正则 + 规则表，**可单元测试**）；
- `Services/LinkLauncher.cs`：协议跳转与软件可用性检测；
- `Services/LinkPromptWindow.xaml(.cs)`：提示卡（复用 U盘小助手卡片语言，右上角弹出）；
- 设置·🧰 工具箱新增「链接助手」区块（不动现有页面结构）。

### 3.2 监测机制：怎么监测？多久一次？

**结论：事件驱动、复制即感知（毫秒级），不复制时零开销、绝不弹窗。**

1. **主方案——`AddClipboardFormatListener`（Win32 消息钩子）**
   系统在剪贴板内容变化时向本窗口发 `WM_CLIPBOARDUPDATE` 消息 → 收到才分析；
   **没有复制动作就没有消息**，这是"不复制不弹"的结构性保证（不是靠定时器判断）。
2. **辅助校验——`GetClipboardSequenceNumber()`**
   消息到达后先比对剪贴板序列号（一次极廉价的 API 调用），去重重复消息；
   该 API 同时用作**兜底轮询模式**的开关（若个别环境下钩子失效，可退化为 500ms 轮询序列号、变化才读取——依旧极低开销）。
3. **读取与识别**
   只在变化事件里读 `CF_UNICODETEXT`；正则提取 URL/口令文本 → 规则表匹配分类。
   识别为纯本地计算，**不上传任何剪贴板内容**（隐私边界写入产品说明）。
4. **时效**：用户按 Ctrl+C 到提示卡弹出 ≈ 50~150ms，可认为"刚复制就检测出来"。

### 3.3 误打扰规避（重点）

| 策略 | 效果 |
| --- | --- |
| 事件驱动，非定时弹窗 | **没复制东西 → 永远不弹** |
| 只认"链接/口令"文本 | 普通文字复制静默忽略 |
| 同链接去重：同一目标 10 分钟内不重复弹（可调） | 连续复制同一分享口令不轰炸 |
| 自排除：轻启自身写入的剪贴板（截图复制/保存并复制/钉图复制）打标记跳过 | 自己的输出不弹自己 |
| 不抢焦点：`ShowActivated=false` + 不激活显示 | 打字/游戏不受影响 |
| 全屏免打扰：检测前台全屏应用（游戏/演示/视频）自动暂停弹窗（可关） | 打游戏不打扰 |
| 分类开关：网盘 / 下载 / 远程 / 会议办公 / 其他 各自独立开关 | 只开需要的 |
| 软件未安装不弹（协议未注册检测） | 装了才提示"跳转到 XX" |
| 自动收起 12 秒；多链接一次只弹一张（队列合并） | 不堆积 |

### 3.4 跳转机制

1. **协议直跳**（首选）：`Process.Start(new ProcessStartInfo(uri) { UseShellExecute = true })`，
   由系统按注册表（`HKCR\<scheme>\shell\open\command`）路由到对应客户端，支持传参入会/转存/远程；
2. **协议可用性检测**：弹窗前查注册表该协议是否已注册 → **未安装对应软件 → 不弹**（或在开关打开时降级提示"用浏览器打开网页版"）；
3. **网页降级**（百度网盘等无深链场景）：默认浏览器打开分享链接，页面自行拉起客户端完成转存；
4. **纯文本口令**（如远程 ID、会议号）：按平台模板构造协议 URI 跳转（ToDesk/向日葵/腾讯会议均支持参数化调用）。

### 3.5 设置项（工具箱「链接助手」区块）

- 总开关：启用链接助手
- 分类开关：网盘 / 下载 / 远程 / 会议办公 / **影音视频** / **网页链接**（兜底）/ 其他
- 选项：全屏免打扰、重复提醒间隔（5/10/30 分钟/关闭）、网页链接按域名去重（5 分钟）、网页版降级提示
- 入口复用：与 U盘小助手、置顶窗口同页排布

## 四、UI 设计（复用现有主题 UI）

复用当前**动态主题资源**（`BgCard`/`TextPrimary`/`AccentBrush`…，深浅色自动适配）与
U盘小助手的卡片设计语言（圆角深色卡、SVG 图标、图标按钮）。

**位置**：屏幕**右上角**（距边 16px），多卡错层向下堆叠；可拖动；12 秒自动收起。

```
┌────────────────────────────────────────────┐
│ 链接助手（小标签）                            │
│ [类目图标]  百度网盘分享链接                   │
│            pan.baidu.com/s/1a2b...（截断）    │
│                               [打开] [忽略]  │
└────────────────────────────────────────────┘
```

- 类目图标用 SVG（计划新增 svg/link/：网盘/下载/远程/会议 4 个类目图标，风格与 svg/set 一致）；
- 主按钮 `打开`（Accent 蓝色，图标+文字），次按钮 `忽略`（关闭卡片）；
- 点"打开"执行跳转并收起；忽略/超时收起且进入去重记录；
- 提示卡**对截屏隐形**（与 U盘小助手一致，不污染截图）。

## 五、实施计划（审核通过后执行）

1. `LinkClassifier` 识别器 + 规则表 + 单元测试（各平台链接样例）；
2. `ClipboardLinkMonitor` 监听（含自排除标记、序列号去重）；
3. `LinkLauncher`（协议注册表检测 + 跳转 + 网页降级）；
4. `LinkPromptWindow` 提示卡 + SVG 类目图标；
5. 设置·工具箱「链接助手」区块 + 设置持久化；
6. 端到端实测（复制真实分享链接/磁力链/会议链接验证弹窗与跳转）→ 本地打包（**不推送 GitHub**）。

## 六、风险与边界

- 各平台链接格式/协议可能随版本变化 → 规则表集中可维护、失效时降级不弹；
- 迅雷链 `thunder://` 为专有编码（AA...ZZ 包裹），直链转迅雷链需按其编码规则构造；
- 部分客户端协议需登录态才有完整体验（如转存需登录网盘），提示卡文案不承诺"自动转存"，表述为"打开 XX 处理"；
- 剪贴板隐私：所有识别在本地完成，不联网、不记录剪贴板历史（去重仅内存）。
