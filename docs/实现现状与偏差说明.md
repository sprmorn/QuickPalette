# 轻启 QuickPalette · 实现现状与偏差说明（2026-10 整改版）

本文档记录代码实现与《轻启-快捷启动器详细设计方案》的差异与新增内容，作为设计文档的**增补附件**。发生冲突时，以本文档描述的实现现状为准。

## 1. 相对设计方案的架构偏差

### 1.1 文件搜索子系统（设计 4.3/10 的偏差，属超设计交付）

设计方案 4.3 写"不做全盘扫描"，但实际实现了一个**可选的全盘文件索引子系统**（约对应 V3 里"文件搜索"能力提前落地）：

- 独立进程 `QuickPalette.FileIndexWorker`（requireAdministrator，独立 exe），主进程通过 `ShellExecuteEx("runas")` 拉起；
- 数据源是 **NTFS USN 变更日志**（`FSCTL_ENUM_USN_DATA` 全量 + `FSCTL_READ_USN_JOURNAL` 增量），不是目录枚举；
- 主进程普通权限、Worker 提权，双进程避免常驻提权；Worker 监控父进程（PID+启动时间）自行退出；
- 快照落盘 `index.bin` + `index.meta.json`，主进程按版本号轮询热加载（双缓冲）；
- **默认可用但可关闭**：设置页可关文件搜索；关闭后启动不弹 UAC，内存回到设计基线（约 30–40MB）；
- 全部打开时内存高于设计 10.1 的 80MB 目标（大型磁盘上索引+工作集约 100–150MB，峰值装载更高），属于**已知偏差**，后续用分段内存映射（V2 路线）收敛。

隐私与安全：索引只含文件名与目录结构元数据；无云同步；数据目录 `%APPDATA%\QuickPalette\FileIndex\`。

## 2. 数据文件（%APPDATA%\QuickPalette\）

| 文件 | 内容 | 备注 |
| --- | --- | --- |
| `apps.json` | 白名单应用 | 纯数组格式（兼容旧工具）；写前分类备份 |
| `schema.json` | Schema 版本戳 | 读取时兼容文件级信封 `{schemaVersion,data}` 与旧条目级 `schemaVersion` |
| `settings.json` | 配置 | `Whitelist`、`FilterSystemComponents`、`ScanSources` 等 |
| `hidden.json` | 隐藏记录 | 防止候选池重新导入已隐藏项 |
| `usage.json` | 使用统计 | 启动次数 + 最近使用时间，服务排序 |
| `backups\` | 自动备份 | `apps_*`/`settings_*`/`pre_migration_*` 按类别各留 10 份 |
| `FileIndex\` | 文件索引快照 | `index.bin` + `index.meta.json`（协议字段见开发指南）；部分卷被排除时 `Status` 仍为 `ready`（保证主进程装载兼容），警告写 `meta.Error`；仅当无任何可用卷时 `Status="warning"` |
| `firstrun.done` | 向导完成标记 | |
| `logs\` | 滚动日志 | `app-yyyyMMdd.log` |

**存储安全保证**：临时文件 + fsync + 原子替换；读失败不覆盖写；损坏从最近可读备份自动恢复；迁移失败回滚；设置页可导出/导入单一 `quickpalette-backup.json`。

## 3. 搜索与排序（对设计 6.2 的具体化）

匹配维度分层（层内加分不跨层）：名称精确 > 名称前缀 > 名称子串 > 拼音全拼 > 拼音首字母 > 别名/标签/DisplayName。

层内加分：收藏 +100、launchCount×2、SortWeight、最近使用指数衰减 `50·exp(-天数/7)`。空输入 = 收藏 + 最近使用。

拼音为**内置码表**生成（约 1200 常用汉字 + 多音字备选读音），离线可用、无第三方依赖；生僻字可通过别名兜底。

## 4. 新增能力清单（本次整改交付）

- 命令模式 `>`、面板拖拽添加（.exe/.lnk/.url）、运行中捕获前台窗口入库
- 拼音搜索真正生效（全拼+首字母）、文件搜索走两级索引（首字符分桶）
- 备份/恢复向导（导出/导入/立即备份/从最近备份恢复/打开数据目录）
- 路径失效"重新定位"引导（重新选择/打开目录/移除）
- 结果增强：命中高亮、应用/文件分组、自适应高度、`Ctrl+1..9`、`Ctrl+C` 复制路径、动态快捷键提示
- 设置补全：MaxResults、过滤规则编辑（关键词/路径/白名单/系统组件开关）、热键录制控件、主题即时预览
- hidden/usage 数据、`HotkeyRecorderControl`、`EditAppWindow` 独立化、`UiText` 轻量双语（zh-CN/en-US）
- 插件 SDK：`PluginManifest` + 插件上下文契约（加载器留待 V3）
- 系统组件直达：内置 Windows 系统组件静态目录 `SystemToolCatalog`（系统工具/控制面板/管理控制台/ms-settings 设置页/系统文件夹），中文名/英文名/命令名/拼音皆可搜，ShellExecute 启动、本机可用性过滤（设计 6.4）
